# 🌈 Sam's Visual Learning Studio

A calm, visual learning website for Sam.

## Current version

- PDF upload in the browser
- PDF text extraction using PDF.js
- One visual learning slide per PDF page
- Key ideas, Sam's Discovery and memory cue
- Previous / Next / First / Last navigation
- Focus Mode
- Browser read-aloud
- Visual Simulator with starter science concepts
- Responsive mobile design

## Important

This first version is frontend-only. Uploaded PDFs are processed in the browser and are not sent to a server. The simulator currently uses lightweight educational templates and keyword recognition.

## Publish with GitHub Pages

Open **Settings → Pages → Build and deployment → Deploy from a branch**, choose **main** and **/(root)**, then Save.

Website address:
https://maliniraijo-max.github.io/sam/

The first publication can take a few minutes.

## Future AI version

A future backend can add:
PDF → OCR/text → AI understanding → richer key points → generated illustrations → generated visual simulations.

Never place a private AI API key directly in this public frontend repository.
